# Guild AI Overlay

This directory is reserved for Guild AI additive modules.

Start with:

- `templates/` for universal guild schema loading.
- `accounting/` for token usage and P&L records.
- `memory/` for SQLite/Chroma adapter selection.
- `llm/` for hardened LLM response parsing.

Do not replace upstream Claw-Empire workflow modules until the adapter layer is stable.
